# AI Chatbot API

A simple Python chatbot that uses the Hugging Face API to generate AI responses.

## Features

- Interactive chatbot
- Takes questions/messages from the user
- Generates AI responses
- Uses Hugging Face Inference API
- Can be stopped by typing `exit`

## Technologies Used

- Python
- Hugging Face API
- Hugging Face Inference Client
- python-dotenv
